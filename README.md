# Sistemas de Control III

Repositorio para la asignatura **Sistemas de Control III** del programa de **Ingeniería Mecatrónica** en la Escuela Tecnológica Instituto Técnico Central.

## Descripción de la Asignatura
Esta asignatura presenta el método para la solución de problemas complejos enfocados en el diseño y análisis de sistemas dinámicos. Los estudiantes aprenderán a identificar una forma nueva de resolución de aquellos problemas que no pueden ser descritos fácilmente mediante un enfoque algorítmico tradicional, apoyándose en el enfoque de **Espacios de Estados**.

## Competencias y Resultados de Aprendizaje
- Diseñar estrategias de control bajo el enfoque de espacios de estados, utilizando herramientas como realimentación de variables de estado y observadores para optimizar procesos dinámicos.
- Evaluar diseños realizados por medio de experimentación y/o simulación, para validar estrategias de control.
- Identificar modelos de sistemas dinámicos lineales y, de ser necesario, emplear la linealización como insumo para su caracterización.

## Temario Principal
- **Representación en Espacio de Estados:** Sistemas de tiempo continuo y discreto, lineales y no lineales.
- **Linealización:** Linealización de sistemas dinámicos.
- **Propiedades del Sistema:** Estabilidad, sensibilidad, robustez, controlabilidad y observabilidad.
- **Formas Canónicas:** Formas canónicas controlables y observables.
- **Diseño de Controladores:** Controladores por realimentación de variables de estado (con y sin integrador).
- **Observadores:** Diseño e implementación de observadores de estado.
- **Control Óptimo:** Controlador cuadrático lineal (LQR) y Gaussiano (LQG).
- **Multivariables:** Introducción al diseño de controladores multivariables.

## Organización del Repositorio
El repositorio está dividido en carpetas por semanas temáticas de acuerdo con el plan de estudios (Syllabus), excluyendo las semanas correspondientes a evaluaciones.
